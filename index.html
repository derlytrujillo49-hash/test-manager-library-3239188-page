Sobre el Proyecto

Manager Library es un sistema de gestión de bibliotecas diseñado para administrar eficientemente el catálogo de libros, clasificaciones por categorías y el control estricto de préstamos vigentes o vencidos para los socios de la institución.

⚡

Arquitectura y Stack Tecnológico

Siguiendo las pautas de Spec-Driven Development (SDD), la especificación de negocio original fue traducida e implementada en los siguientes entornos de desarrollo:

Frontend React
Backend PHP Laravel
Base de Datos PostgreSQL
🚀

Capacidades Implementadas

  • ✔ Modelo Físico Robusto: Migraciones relacionales completas con control estricto de restricciones concurrentes (disponibilidad de ejemplares).
  • ✔ Contrato API v1: Enrutamiento estructurado para flujos operativos de autenticación, búsqueda indexada y reportes de uso.
  • ✔ Interfaz de Usuario Reactiva: Componentes desacoplados para búsqueda dinámica y validación de reglas de negocio en formularios.
