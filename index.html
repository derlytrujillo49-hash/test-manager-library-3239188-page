Sobre el Proyecto

Manager Library es un ecosistema digital de gestión diseñado para administrar el catálogo físico de libros, clasificaciones por categorías y el control de préstamos para los socios de la institución. El proyecto nace de una especificación técnica estricta y demuestra la capacidad de traducir reglas de negocio abstractas a componentes de software funcionales.

Arquitectura y Stack Tecnológico

Siguiendo las pautas de Spec-Driven Development (SDD), el diseño original fue interpretado e implementado de forma desacoplada utilizando un stack de desarrollo moderno, seguro y altamente escalable:

Entorno Cliente React (Vite)

Interfaz SPA reactiva basada en componentes modulares y estados controlados para las validaciones del operador.

Servicio API PHP Laravel

Capa lógica central encargada de procesar las transacciones complejas, control de accesos y el enrutamiento v1.

Motor de Datos PostgreSQL 16

Almacenamiento relacional operando estrictamente en zona horaria UTC, con restricciones CHECK y claves UUID.

Reglas de Negocio e Integridad de Datos

El sistema aplica las políticas innegociables del documento de especificación a nivel de software y base de datos:

  • ✦
    Control de Ejemplares (CHECK Constraint)

    La base de datos asegura de forma nativa que los libros disponibles permanezcan en un rango válido mayor o igual a cero y menor o igual al inventario total.

  • ✦
    Límite Transaccional de Préstamos

    Tanto la interfaz en React como el Backend en Laravel validan que un proceso de préstamo contenga un límite estricto de mínimo 1 y máximo 3 líneas de libros por sesión.

  • ✦
    Preservación Histórica Inmutable
