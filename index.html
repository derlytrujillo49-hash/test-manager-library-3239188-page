System Core Features (SDD)

Dynamic Catalog

Advanced book search with real-time text query parameters, full pagination, and safe software-level record soft deletion (`deleted_at`).

Transactional Integrity

Strict domain rule execution engine. Restricts loan transactions to a strict boundary limit of 1 to 3 active catalog items per workflow session.

Protected structural operations framework designed exclusively for isolated secure roles (`admin` and `librarian`).
